What this is

This is a demo of SuggestAPI + Claude Commerce Agents. It shows SuggestAPI ranking a catalog for Anthropic’s commerce-agent tools. You act as the shopper; the page runs those tools so you can watch the integration. Claude itself is not in this loop — wire SuggestAPIStorefront into Anthropic’s shopping agent when you want the model.

How to use this demo

  1. Tap a search (the same queries as the harness tests).
  2. Add a ranked product — the cart icon opens a tray.
  3. Open the cart, send the checkout tool, then continue on the merchant page. No payment.
